# README artwork

`readme-hero.svg` follows the Speakeasy brand skill from
`speakeasy-api/marketing-content-generation` at commit
`24edadffa1c632b5a98f15475caca2c82bd552c7`.

The palette and wordmark come from that brand system. Typography uses its
approved free-font alternatives: Taviraj Thin, Geist Light, and Geist Mono
Regular, from the Google Fonts `ofl/taviraj`, `ofl/geist`, and `ofl/geistmono`
directories. All lettering is converted to SVG paths. No font binaries or
external font requests are included in this repository or required to display
the artwork.

The banner uses a neutral split layout, one thin RGB accent, and a visible grid.
The SQL is illustrative; the accompanying README documents the actual policy and
transport behavior. The SVG includes an accessible title and description.
